# Reproducibility

## Machine used for smoke

See `artifacts/environment.json` (generated by `scripts/collect_environment.py`). Expected class: macOS arm64, Apple M4, 16 GB RAM, no CUDA.

## Commands

```bash
uv python pin 3.11
uv sync --extra dev --extra train
make smoke
make test
python scripts/validate_k8s.py
```

Seeds default to **42** in `configs/`. `set_global_seed` sets `random`, NumPy, `PYTHONHASHSEED`, and Torch (including MPS when present).

## What is and is not reproduced here

| Artifact | Reproduced on this laptop |
|----------|---------------------------|
| Fixture corpus + quality report | Yes |
| Fallback SFT/DPO loss curves | Yes if TRL cannot run |
| Tiny HF LoRA SFT/DPO | Attempted; see `artifacts/sft_train_metrics.json` |
| Qwen3-4B QLoRA | No — **Not benchmarked on this hardware.** Clone on NVIDIA and follow [GPU_SETUP.md](GPU_SETUP.md). |
| vLLM serving | No |
| Docker Compose live | Only if the daemon is up |

## Configs that must not be reported as executed

`configs/cuda/`, `configs/cloud/`, `cloud/run_gpu_training.sh`.

## Data

Generator is deterministic given `(n_families, n_variants, seed)`. Loghub download is best-effort and not required for smoke.
